# FC27 FUTBIN 市场监控与价格采集扩展

这个 Chrome / Edge Manifest V3 扩展读取用户当前正常浏览的 FUTBIN FC27 球员 Market 页。它可以采集 PC 最低价、按阈值发送 Windows 桌面通知、监控 EA 价格范围、读取 PC「Latest Sales」可见记录中的最低成交价和成交时间，并每 15 分钟保存一次市场样本。它不请求 FUTBIN API，不读取或保存 Cookie，也不尝试通过 Cloudflare 验证。

## 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选择本目录 `browser-extension`。
4. 固定“FC27 FUTBIN 市场监控”扩展，方便从 FUTBIN 页面使用。

扩展只声明 FUTBIN 网站权限；批次和采集结果保存在浏览器本机扩展存储中。

升级旧版本后，请在扩展管理页点击一次“重新加载”，让新增的后台监控和桌面通知权限生效。

从 1.3.1 起，后台检查前会主动注入当前版本的 Market 探针，并使用独立的 V2 消息通道。这样即使标签页还保留着旧版脚本，或 FUTBIN 通过站内路由从 Summary 切到 Market，也不会继续调用只认识详情页的旧探针。卡片读取失败时，扩展会在“读取失败”下直接显示具体原因。

## 使用

1. 在 FC27 工具网页选择最多 10 张卡，价格来源选 FUTBIN，下载 `cards.csv`。
2. 打开扩展，载入这个 `cards.csv`。
3. 点“打开下一张 / 球员目录”。已有映射时会直接打开 FUTBIN 球员 Market 页；首次使用时会打开 FUTBIN FC27 球员目录并自动填入球员名字，然后手动选择评分和版本正确的卡片。
4. 等页面的 PC 价格显示后，打开扩展并点“采集当前 FUTBIN 页面”。扩展核对 FUTBIN 页面 EA ID 是否在批次中，并核对评分；成功后会记住该 EA ID 对应的 FUTBIN Market 页。
5. 对下一张重复操作。之后扩展会直接打开已经确认过的卡片页。
6. 点“导出 prices.csv”，再用项目现有命令导入并生成报告：

```powershell
python -m fc27 import <导出目录>/futbin-prices.csv
python -m fc27 report --out output/live
```

扩展只导出有有效 PC 报价的行。页面缺价时会记为“无报价”，但不生成无效的价格 CSV 行。FUTBIN 仅提供相对更新时间，因此 CSV 的 `source_time` 留空，`collected_at` 记录点击采集的时间。

## PC 市场与顶价监控

1. 打开扩展，在“PC 市场监控”中点击“选择新球员”，或自行打开任意 FUTBIN FC27 球员详情页。
2. 确认评分和版本正确，等待页面显示 PC 价格和“价格范围”后，点击“添加当前卡片”。
3. 扩展以 FUTBIN 站内卡片页面 ID 区分具体版本，因此同一球员的金卡、TOTW 和其他特殊卡可以分别监控。添加后当前标签会自动跳转到 `/market`，旧版已保存的 Summary 链接也会自动迁移。
4. 在卡片的“提醒最高价”中填入数字，表示最低价小于等于该值时提醒；同时填写下限和最高价则表示进入这个区间时提醒。通知只在“从区间外进入区间内”时发送，价格离开区间后才会重新武装，避免每分钟重复弹窗。清空两项并保存可关闭价格提醒。
5. 保持浏览器运行。扩展每分钟检查报价、EA 价格范围，以及 PC「Latest Sales」当前显示的销售记录；每 15 分钟记录一次最低价、五档可见报价、最低价同价张数、最低价上方 5% 内的张数、最近销售最低成交价及其时间。每张卡保留最近 672 条记录（约 7 天）。
6. “立即检查并记录”会强制保存一次当前样本；“导出市场记录”生成 `futbin-market-history.csv`；“测试通知”用于确认 Windows 通知是否正常显示。

验证自动刷新时，保持监控页和浏览器打开，等待超过一分钟后重新打开扩展。“最近检查”时间应更新；再等待一分钟并重开扩展，时间应再次前进。当前激活的监控页也会刷新，因此正在浏览该页时可能被打断。

若关闭了置顶监控页，该卡会显示“需处理”；点击卡片的“打开 Market”或“打开全部 Market 页”即可恢复。监控速度受 FUTBIN 自身更新速度和页面验证状态限制，通知时间是 FUTBIN 显示新数据后的下一个检查周期，并非直接来自 EA。

## 当前边界

- 每批最多 10 张卡，且每张 EA ID 必须唯一。
- FUTBIN URL 中 `/27/player/<数字>/` 的数字是 FUTBIN 站内卡片 ID，不能由 FUT.GG 的 `player_id` 或 EA ID 直接拼接。首次手动选择正确详情页并完成采集后，扩展会保存该 EA ID 对应的 FUTBIN URL，后续直接复用。
- FUTBIN 页面出现验证、错误或未显示价格时，扩展不会自动处理验证；可在正常浏览器中完成访问后重试。
- 更换批次会清除当前批次的采集记录，但已确认的 EA ID 到 FUTBIN 页面链接仍会保留。
- 扩展读取页面 JSON-LD 的 EA ID，以及与当前 FUTBIN 站内卡 ID 相同的 PC 价格框。它不把 FUTBIN 站内卡 ID 当作 EA ID。
- 市场监控要求对应 FUTBIN Market 页和浏览器保持打开；扩展每分钟会刷新监控页，包括当前激活的页面。
- “挂卡数”是 FUTBIN 价格框展示的最低五个报价槽位的样本深度，不是 EA 全市场的活动挂单总量；它适合观察近端供给拥挤度，但不能当作完整市场库存。
- FUTBIN 报价属于第三方快照，不等同于已确认成交价。交易决策还应考虑页面更新时间、流动性和 EA 5% 交易税。
- 「Latest Sales 最低成交」只在页面当前显示的 PC 销售列表中取最小值；不使用主机市场的记录，也不使用页面另列的「Cheapest Sale」历史统计。弹窗显示对应成交的北京时间。若页面提供带时区的机器时间戳，扩展直接换算；若仅提供英国页面时间文字，按 Europe/London 时区解释，自动处理英国夏令时。旧版误按浏览器本地时区保存的样本在显示和导出时也会重新换算。夏令时切换造成无法唯一判断的时刻会保留页面原文。
