# FC27 FUTBIN 市场监控扩展

这个 Chrome / Edge Manifest V3 扩展读取正常浏览的 FUTBIN FC27 球员 Market 页，监控 PC 最低价、EA 价格范围、可见报价深度与 Latest Sales。它不请求 FUTBIN API，不读取或保存 Cookie，也不尝试绕过网站验证。

## 安装与升级

1. 打开 `edge://extensions` 或 `chrome://extensions`，开启“开发人员模式”。
2. 选择“加载解压缩的扩展”，指向包含 `manifest.json` 的目录（在 FC27 工具项目中是 `browser-extension`，在独立扩展仓库中是仓库根目录），并固定扩展图标。
3. 升级原安装位置时，在扩展管理页点击“重新加载”。原监控列表和历史记录会继续保留。

如果改用其他目录或电脑安装，浏览器可能把它视作新的扩展实例，不会自动共享本机存储。请先在旧扩展点击“备份监控数据”，再在新扩展点击“恢复监控数据”。确认新扩展能显示卡片和历史后，再移除旧扩展。备份是 JSON 文件，包含监控卡片、提醒规则和市场历史，不包含早期的数据库批次采集数据。

## 使用

1. 点击“选择新球员”，在 FUTBIN FC27 球员目录中手动选择评分和版本正确的卡片；也可以直接打开任意球员详情页。
2. 等页面显示 PC 报价与价格范围后，在扩展中点击“添加当前卡片”。扩展按 FUTBIN 站内卡片 ID 区分不同版本，并把当前标签切换到 `/market`。
3. 卡片的“提醒最高价”表示最低价小于等于该数值时通知；同时填写下限和最高价则表示进入该区间时通知。只有价格从区间外进入区间内才会再次通知，避免每分钟重复弹窗。清空两项即可关闭提醒。
4. 保持浏览器和对应 Market 标签页打开。扩展每分钟刷新并检查一次价格、价格范围和 Latest Sales；每 15 分钟记录最低价、可见报价、最低价同价张数、最低价上方 5% 内的张数以及最近销售最低成交价。每张卡最多保留 672 条历史（约 7 天）。
5. “立即检查并记录”会强制保存一次样本；“导出市场记录”生成 `futbin-market-history.csv`；“测试通知”用于检查 Windows 桌面通知。

“备份监控数据”生成可恢复的 JSON。“恢复监控数据”会合并市场历史；同一张卡若已存在，则保留当前扩展中的提醒规则。恢复后点击“打开全部 Market 页”，让定时检查重新获得可刷新的标签页。不要把“导出市场记录”的 CSV 当作恢复文件；它只适合分析历史数据。

## 边界与隐私

- FUTBIN URL 中 `/27/player/<数字>/` 的数字是 FUTBIN 站内卡片 ID，不能由 EA ID 或 FUT.GG 的 `player_id` 直接拼接。
- “挂卡数”只统计 FUTBIN 页面可见的最低五个报价槽位，不是 EA 全市场的活动挂单总量。
- FUTBIN 报价是第三方快照，不等同于实时市场或已确认成交价。通知最快也只能在 FUTBIN 更新页面、扩展下一次检查后出现。
- Latest Sales 最低成交只取页面当前显示的 PC 销售记录。带时区的时间戳直接换算为北京时间；仅有英国页面时间文字时按 `Europe/London` 解释，含夏令时处理。无法唯一判断的时刻保留页面原文。
- FUTBIN 页面出现验证、错误或缺价时，扩展不会自动处理验证。关闭监控页后可用“打开 Market”或“打开全部 Market 页”恢复。
- 旧版的 `cards.csv` 批次采集入口已经移除。旧版存储中的批次数据不会被自动删除，但新版不再读取或写入它们。
